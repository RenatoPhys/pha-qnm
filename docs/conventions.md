# Conventions

- Signature: mostly plus.
- AdS radius: `L=1`.
- Fourier convention: `exp(-i omega v + i k z)`.
- Stable QNMs: `Im(omega)<0`.
- Numerical horizon gauge: `r_H=0`, `A_H=0`, `h_H=0`, `h'_H=1`, `Phi_H=0`.
- Independent horizon data: `(phi0, Phi1)`.
- Primary compact coordinate: `u=exp(-A)`, with boundary `u=0` and horizon `u=1`, only when `A'>0` everywhere.
- Dimensionless frequency and momentum: `w=omega_phys/(2 pi T)`, `q=k_phys/(2 pi T)`.
- A characteristic time `-1/Im(omega)` is called a linear relaxation time, not a thermalization time.
- Results describe a lattice-calibrated holographic EMD model, not QCD itself.
